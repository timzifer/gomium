# libcef exports gomium calls directly. Source of truth for tools/cefshim -
# it generates cef_shim.S, cef_shim.c and cef_shim_symbols.go from this list,
# and slot order in all three follows file order.
#
# Rules:
# - Real export names only. The cef_string_clear / cef_string_to_utf8 /
#   cef_string_userfree_free macros from include/internal/cef_string.h
#   resolve to the cef_string_utf16_* exports listed at the bottom.
# - Never list cef_*-prefixed helpers defined in this repo (v8.c,
#   v8_value.go preamble) - they would collide as duplicate symbols.
# - A symbol missing here fails the build with an undefined reference, so
#   the list cannot silently go stale.
